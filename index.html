About audio quality

Playback uses the Web Audio API with a piano-like tone (triangle + sine oscillators, shaped envelope). For realistic instrument sounds you'd load a SoundFont (e.g. MuseScore's free General MIDI SF2) via a library like soundfont-player or WebAudioFont — but that adds ~10 MB of audio samples. The current tone is clean and accurate for pitch/rhythm checking.
